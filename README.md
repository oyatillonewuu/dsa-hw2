### DSA homework 2

Source: [github.com/oyatillonewuu/dsa-hw2](https://github.com/oyatillonewuu/dsa-hw2) 

Note: I guarantee that no part in this project was written by AI and that this is purely human work.

Credits: Learned the implementation algorithms/ideas from:

- facebook/folly
- https://github.com/TheAlgorithms/Python
- programiz
- and others.

Implemented:

- Min heap
- Max heap
- Heap sort using min heap
- Priority queue using array

Locations:

- heap_oop -- the implementation of heaps using C++ classes
- heap_procedural -- bare minimum implementations designed for array/vector
- pqueue -- contains the implementation of an array-based queue

The branch `autograder` is designed for autograder with solution files named "problem*.cpp".
For more humane version, see the `main` branch.

On the branch `autograder`, you just need to compile the solution files.

In contrast, on the `main` branch, there are special `build.sh` files to automate the process. They will create `build` files. To run, you should execute `bash build.sh` in their directories (linux/unix based OS is recommended).
